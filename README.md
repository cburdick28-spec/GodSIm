# GodSim

A web-based Grand Strategy & God-Sim hybrid: an Endless Sky-style supply/demand
market economy, Civilization-style nation ruling, and a WorldBox-style sandbox
god mode.

## Stack

- Next.js (App Router) + React + TypeScript
- Tailwind CSS
- Zustand for the global simulation state
- Lucide icons

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
